Blockchain-based Federated Learning with Reputation Token Incentives

4 Proposed Protocol

This section presents a blockchain-based federated learning framework tailored for Internet of Things (IoT) environments. The framework introduces a reputation token incentive mechanism to encourage honest behavior and sustained participation from high-quality nodes. The system consists of four core components: task publisher, participating nodes, blockchain network, and smart contracts.

The task publisher defines the learning objective, data requirements, model type, and total reward tokens. Participating nodes register as training or validation nodes by staking tokens, which are converted into initial reputations. The blockchain network maintains task information, model parameters, and interaction logs in a transparent and tamper-resistant manner, while smart contracts orchestrate node selection, training coordination, reputation updates, and token settlement.

4.1 System Model

The framework distinguishes between training nodes and validation nodes. Training nodes perform local updates on their private datasets and upload model updates to the blockchain. Validation nodes reconstruct candidate models from submitted updates and the global model, evaluate them on a public validation dataset, and provide feedback used to adjust the reputations of training nodes.

4.3 Participant Selection Algorithm

Algorithm 1 Participant Selection and Reputation Management
Input: Candidate sets $N_t, N_v$, staked tokens $\{C_i\}$, decay factor $\delta_d$, weights $\alpha, \beta, \gamma, \delta_r$, target sizes $k_t, k_v$.
Output: Selected training nodes $N_t'$, selected validation nodes $N_v'$.
1 $N \leftarrow N_t \cup N_v$
2 $C_{avg} \leftarrow \frac{1}{|N|} \sum_{i \in N} C_i$
3 For each node $i \in N$ compute reputation $R_i$ with decay.
4 $S_i \leftarrow \alpha R_i + \beta\left(\frac{C_i}{C_{avg}}\right)^\gamma + \delta_r \Delta R_i^{\mathrm{decay}}$
5 Sort $N_t$ and $N_v$ by $S_i$ and take top $k_t$ and $k_v$.

基于区块链的声誉激励联邦学习框架

4 协议设计

本节面向物联网场景给出一种基于区块链的联邦学习框架。 框架通过引入声誉代币激励机制，引导高质量节点长期、诚实地参与训练。 系统由任务发布者、参与节点、区块链网络和智能合约四个核心组件构成。

任务发布者首先给出学习目标、数据需求、模型类型以及总奖励代币。 参与节点通过质押代币注册为训练节点或验证节点，质押代币被映射为初始声誉值。 区块链网络以透明、防篡改的方式记录任务信息、模型参数和交互过程， 智能合约负责节点选举、训练流程协调、声誉值更新以及奖励结算。

4.1 系统模型

框架区分训练节点和验证节点两类角色。 训练节点在本地私有数据集上执行模型更新，并将参数更新上传到区块链。 验证节点基于提交的更新和全局模型重构候选模型，在公共验证数据集上计算性能， 并将结果反馈给智能合约，用于调整训练节点的声誉值。

4.3 参与者选举算法

算法 1 参与者选举与声誉管理
输入： 训练与验证节点候选集 $N_t, N_v$，质押代币 $\{C_i\}$，衰减因子 $\delta_d$， 权重系数 $\alpha, \beta, \gamma, \delta_r$，目标节点数 $k_t, k_v$。
输出： 选中的训练节点集合 $N_t'$ 与验证节点集合 $N_v'$。
1 $N \leftarrow N_t \cup N_v$
2 $C_{avg} \leftarrow \frac{1}{|N|} \sum_{i \in N} C_i$
3 对每个节点 $i$ 计算衰减后的声誉值 $R_i$。
4 $S_i \leftarrow \alpha R_i + \beta\left(\frac{C_i}{C_{avg}}\right)^\gamma + \delta_r \Delta R_i^{\mathrm{decay}}$
5 按 $S_i$ 对 $N_t$ 与 $N_v$ 排序，分别取前 $k_t$ 与 $k_v$ 个节点。
